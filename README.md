# Quota Reset Index

A public, append-only, evidence-linked ledger of every discretionary AI quota reset issued by OpenAI (Codex) and Anthropic (Claude Code). Each record carries a real source URL, a confidence grade, and a precision-tagged timestamp, so the ledger is citable on its own and makes no predictions it could be wrong about. Two forecasting models sit on top of it — a self-exciting intensity for Codex, a renewal hazard with covariates for Claude Code — and every number they render is labelled uncalibrated until a Brier score replaces the label.

---

Build order is fixed: ledger first, sentinel second, models third, public page last. Work proceeds in approval-gated phases per the build spec, which the operator holds. Current status: **Phase 0 complete, awaiting `APPROVED PHASE 0`.**

This project does not write to kingy.ai, its database, its theme, its mu-plugins, or its uploads.
